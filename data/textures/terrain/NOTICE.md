# Terrain textures

Every texture set in this folder comes from [Poly Haven](https://polyhaven.com) and is licensed CC0 (public domain).
Each folder is named after its Poly Haven asset id and holds the 1k JPG maps: `diff` (albedo), `nor_gl` (OpenGL normal),
`arm` (ambient occlusion, roughness, metalness) and `disp` (height).

- aerial_grass_rock, dry_ground_01, aerial_beach_01, rocky_terrain_02, snow_field_aerial (Earth)
- moon_01, moon_dusted_02 (Moon)
